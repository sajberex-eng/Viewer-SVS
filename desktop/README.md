# Настольная программа HemCenterHistoDigital

Тот же вьювер, что и веб-сервис, но в окне на одном компьютере (Windows или
Mac с чипом Apple Silicon): без сервера, без интернета, без логина и
пароля. Сканы открываются прямо из папок компьютера — не копируются и не
меняются. Техническое задание —
[docs/TOR-desktop.md](../docs/TOR-desktop.md).

Готовые архивы лежат на странице выпусков репозитория
(github.com/sajberex-eng/Viewer-SVS/releases): `…-Windows.zip` и
`…-macOS-AppleSilicon.zip`.

## Как пользоваться на Mac

1. Скачать `…-macOS-AppleSilicon.zip`. Safari распаковывает архив сам, и в
   «Загрузках» сразу лежит `HemCenterHistoDigital.app`; в другом браузере —
   двойной щелчок по zip. Перенести `HemCenterHistoDigital.app` в
   «Программы» (из «Загрузок» macOS запускает программу из временной папки,
   это работает, но хуже). Нужен Mac с чипом
   M1 или новее и macOS 12 и новее.
2. Подписи разработчика у программы нет (решение заказчика), поэтому при
   первом запуске macOS напишет, что не может проверить программу.
   Открыть «Системные настройки» → «Конфиденциальность и безопасность»,
   внизу нажать «Всё равно открыть» рядом с названием программы и
   подтвердить паролем Mac. Это нужно один раз.
3. В каталоге — «Добавить папку» и выбрать папку со сканами. Работают
   форматы, которые читает OpenSlide (SVS, NDPI, TIFF и другие). **KFB на
   Mac пока не открывается** — такие файлы видны в «Не открылись».
4. Программа хранит своё в `~/Library/Application Support/HemCenterHistoDigital`
   (база, кэш, журнал `logs/app.log`). Сканов там нет. Закрытие окна
   закрывает программу.

## Как пользоваться на Windows

Если окно не открывается («Unhandled exception in script», в трассе `pythonnet`
и `Python.Runtime.dll`): Windows пометила файлы архива как скачанные из
интернета. С версии 1.0.1 программа сама снимает эту пометку при запуске; на
версии 1.0 — правой кнопкой по zip → «Свойства» → «Разблокировать», затем
распаковать заново.

1. Скопировать папку `HemCenterHistoDigital` куда удобно, например в
   `C:\Программы\`. Установщика нет, права администратора не нужны.
2. Запустить `HemCenterHistoDigital.exe`. Ярлык на рабочий стол — правой
   кнопкой по файлу → «Отправить» → «Рабочий стол (создать ярлык)».
3. При первом запуске файла, скачанного из интернета, Windows может показать
   «Windows защитила ваш компьютер»: нажать «Подробнее» → «Выполнить в любом
   случае». У программы нет цифровой подписи (решение заказчика), это
   предупреждение показывается один раз.
4. В каталоге — «Добавить папку» и выбрать папку, где лежат сканы. Подпапки
   появятся в дереве так же, как на диске.
5. Если файлы в папке добавили, переименовали или перенесли — «Обновить».
   Аннотации и расчёты остаются при скане и после переименования.

Где программа хранит своё: `%LOCALAPPDATA%\HemCenterHistoDigital` — база
(аннотации, расчёты, названия), кэш изображений, журнал `logs\app.log`.
Сканов там нет. Чтобы начать с чистого листа — закрыть программу и удалить
эту папку. Обновление программы — заменить папку `HemCenterHistoDigital`
новой: служебная папка при этом не трогается.

Оценка клеточности алгоритмом работает без интернета. Оценка ИИ — только
при интернете и после ввода своего ключа в «Настройках»; при ней фрагменты
изображения ткани отправляются поставщику ИИ.

Сканы KFB открываются, если на компьютере установлена программа KFSlideOS:
наша программа берёт у неё библиотеку KFBio. Без KFSlideOS файлы KFB видны
в каталоге в разделе «Не открылись» с этой причиной.

## Как выпустить (обе системы)

Обе программы собирает GitHub Actions (`.github/workflows/desktop.yml`): Windows
на `windows-latest`, Mac на `macos-15` (arm64). Mac для сборки не нужен.

```
git tag desktop-v1.0
git push origin desktop-v1.0
```

По тегу `desktop-v*` проходят тесты, собираются обе программы, проверяется запуск
`.app` и появляется выпуск на GitHub с двумя архивами. Без тега, для пробы:
вкладка Actions → «Настольная программа» → Run workflow (архивы остаются
артефактами запуска, 90 дней). У Mac-сборки в артефактах `macos-diagnostics`
лежат журнал программы и снимок экрана runner. Архив Mac делается только
командой `ditto`: обычный zip теряет символические ссылки внутри `.app`.

## Как собрать на Windows (разработчику)

Нужен Windows 10/11 и Python 3.12. Команды — из папки проекта.

```
winget install --id Python.Python.3.12 -e --source winget --scope user
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
```

Запуск из исходников, без сборки:

```
.venv\Scripts\python.exe -m desktop.launcher
```

Сборка (около трёх минут):

```
.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath build\dist --workpath build\work desktop\app.spec
```

Готовая программа — папка `build\dist\HemCenterHistoDigital` (около 340 МБ,
больше всего занимают llvmlite для Numba и OpenCV). Для передачи —
запаковать её в zip.

Проверка без рабочей служебной папки: переменная `HCHD_HOME` задаёт другую
папку вместо `%LOCALAPPDATA%\HemCenterHistoDigital`. Порт отладки окна —
`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9333`: через
него страницу программы можно проверять сценарием (Chrome DevTools Protocol).

## Устройство

- `launcher.py` — одна копия (мьютекс Windows, на macOS файл-замок
  `instance.lock`; вторая выводит вперёд окно первой), служебная папка и `config.yaml` в ней, сервер uvicorn на
  `127.0.0.1` и свободном порту, окно pywebview (WebView2) на адресе входа с
  одноразовым ключом. Системные окна выбора папки и «Сохранить как» даёт
  pywebview. Программа входит в «задание» Windows: при её закрытии или
  падении система завершает и расчёт клеточности, и процессы WebView2.
- `app.spec` — сборка PyInstaller в режиме «папка»; `server/` кладётся
  исходниками, иначе Numba не кэширует скомпилированные функции.
- `icon.ico` — значок, отрисован из `web/static/img/logo.svg`.
