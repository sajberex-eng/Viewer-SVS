# Техническое задание: настройка изображения в веб-вьювере гистосканов

Раздел 7 ТЗ «Веб-сервис хранения и просмотра гистосканов SVS (HemCenterHistoDigital)» в редакции от 2026-09-29 и требования этапа 12 (раздел 13.9). Здесь собрано только то, что реализовано и выложено 2026-09-29. Источник — дополнение заказчика «Изменение настройки изображения в веб-вьювере гистосканов» и его решения в тот же день: «Авто» работает как в сканере, профиль сканера из файла применяется по умолчанию, добавлены пресеты разделения окрасок, пипетка показывается значком.

## 1. Основание

По отзывам патологов ползунками баланса красного, зелёного и синего не пользуются. Удобны инструменты, привычные по графическим редакторам: чёрная и белая точки с гистограммой, гамма, пипетка белого и автокоррекция. Панель настройки изображения перестраивается вокруг них.

## 2. Что меняется

| Было | Становится |
| --- | --- |
| Восемь ползунков: яркость, контраст, гамма, насыщенность, оттенок, баланс красного, зелёного, синего | Гистограмма и три маркера уровней: чёрная точка, гамма, белая точка |
| Баланс каналов задаётся ползунками и пипеткой | Баланс белого задаётся только пипеткой и кнопкой «Авто», ползунков нет |
| Автокоррекции нет | Кнопка «Авто», работает как калибровка сканера |
| Профиль сканера из файла не используется | Отметка «Цвет как в сканере», включена по умолчанию, если профиль есть в файле |
| Все ползунки видны всегда | Яркость, контраст, насыщенность, оттенок в свёрнутом блоке «Дополнительно» |
| Три пресета | Пять: добавлены «Только ядра (гематоксилин)» и «Только эозин» |

Без изменений: «До/После», «Сбросить всё», сохранение настроек по слайду, ссылка на поле зрения с настройками, мини-карта и миниатюры без коррекций, панель одна на обе половины при сравнении двух сканов.

## 3. Панель настройки

Выдвигается справа, ширина около 300 px, не перекрывает панель увеличений и мини-карту. Сверху вниз:

1. **Пресет**: «Исходное», «Бледная окраска», «Перекрашенный препарат», «Только ядра (гематоксилин)», «Только эозин», «Свои значения».
2. **Отметка «Цвет как в сканере»**: применяет ICC-профиль сканера, записанный в файле. Включена по умолчанию, если профиль есть; недоступна с подсказкой «В файле этого скана нет цветового профиля», если профиля нет (KFB).
3. **Гистограмма** яркости видимого поля зрения, высота около 80 px. Строится по изображению до коррекций. Вертикальная ось в корневом масштабе, чтобы пик фона стекла не скрывал ткань. Участки за чёрной и белой точками затенены. Линии отдельных каналов не показываются.
4. **Шкала уровней** от чёрного к белому с тремя маркерами: чёрная точка, гамма, белая точка. Маркер гаммы стоит между чёрной и белой точками, значение 1,00 посередине; сдвиг влево увеличивает гамму (средние тона светлеют), как в Levels графических редакторов.
5. **Числовые поля** под маркерами: чёрная точка, гамма, белая точка.
6. **Кнопки**: «Авто», пипетка белого (значком пипетки, название в подсказке), «До/После», «Сбросить всё»; при сравнении двух сканов — «Применить к обеим».
7. **Подсказка** пипетки и сообщения об ошибках — на отдельной плашке, показывается только когда есть текст.
8. **Блок «Дополнительно»**, отделён линией, свёрнут по умолчанию: ползунки яркости, контраста, насыщенности, оттенка с числовыми полями; список «Окраска» (вся / только гематоксилин / только эозин); строка «Баланс белого» с текущими коэффициентами трёх каналов (или «не задан») и кнопкой сброса; подпись с порядком применения.

## 4. Параметры

| Параметр | Диапазон | По умолчанию | Назначение |
| --- | --- | --- | --- |
| Чёрная точка | 0…254 | 0 | Уровень, который становится чёрным: проработка бледных ядер |
| Белая точка | 1…255 | 255 | Уровень, который становится белым: фон стекла в чистый белый |
| Гамма | 0,20…3,00 | 1,00 | Нелинейная коррекция средних тонов |
| Яркость | −100…+100 | 0 | Общий сдвиг светлоты |
| Контраст | −100…+100 | 0 | Растяжение или сжатие тонового диапазона |
| Насыщенность | −100…+100 | 0 | Усиление бледной окраски; −100 даёт оттенки серого |
| Оттенок | −180°…+180° | 0° | Компенсация сдвига цвета сканера |
| Баланс белого | три коэффициента 0,5…2 | 1, 1, 1 | Задаётся пипеткой и кнопкой «Авто». В панели показывается коэффициентами; хранится и передаётся в ссылке в единицах −100…+100 (коэффициент `2^(b/100)`), чтобы сохранённые настройки и ссылки прежнего формата читались без преобразования |
| Окраска | вся / только гематоксилин / только эозин | вся | Разделение окрасок H&E по Ruifrok и Johnston (векторы «H&E default» QuPath): показать только ядра или только эозин |
| Профиль сканера | вкл / выкл | вкл, если профиль есть в файле | ICC-профиль из файла переводится сервером в таблицу цвета, шейдер применяет её первым шагом. Выключение запоминается в браузере по скану; в ссылку не входит; «Сбросить всё» включает обратно |

Чёрная точка всегда меньше белой: при движении одного маркера второй не сдвигается, ограничивается движущийся.

## 5. Порядок применения и формулы

Все коррекции выполняются в браузере поверх загруженных тайлов (WebGL-шейдер). Исходный файл не меняется, тайлы при движении маркеров повторно не загружаются. Значения каналов в долях 0…1.

1. Профиль сканера: трилинейная выборка из таблицы цвета «профиль → sRGB» (если отметка включена).
2. Разделение окрасок: `OD = −ln c`, концентрации `M⁻¹·OD`, оставляется одна окраска, `c = exp(−M·conc)`; `M` — матрица из векторов гематоксилина, эозина и остатка.
3. Баланс белого: `c × k`, где `k` от 0,5 до 2 для каждого канала.
4. Чёрная и белая точки: `(c − black) / (white − black)`.
5. Яркость и контраст: `(c − 0,5) × 3^(контраст/100) + 0,5 + яркость/200`.
6. Гамма: `c^(1/гамма)`; результат ограничивается 0…1 до и после.
7. Насыщенность: смешение с яркостью Rec. 709 с коэффициентом `1 + s/100`; затем оттенок: поворот вокруг серой оси.

Без профиля, при окраске «вся», чёрной точке 0 и белой 255 изображение совпадает с прежней редакцией при тех же значениях остальных параметров.

## 7. Автокоррекция

«Авто» повторяет калибровку сканера, а не автоуровни графического редактора: сканер выравнивает белое по пустому стеклу и кладёт фон на уровень около 240–245, не в чистый белый, а чёрную точку не трогает — ядра не «дожимаются».

Считается по обзорному изображению всего препарата (миниатюра 320 px), а не по видимому полю: на 40× фона в поле может не быть, а результат не должен меняться при панорамировании и должен повторяться при повторных нажатиях.

1. Пиксели за пределами скана не учитываются. Если включён профиль сканера, цвета миниатюры сначала переводятся через его таблицу — так же, как это делает шейдер.
2. Фон: 99-й процентиль каждого канала. Баланс белого = отношение максимума из трёх к значению канала — фон становится нейтральным.
3. Белая точка = `уровень фона × 255 / 245`, не выше 255: фон ложится на 245. Если фон уже светлее 245, белая точка остаётся 255.
4. Чёрная точка, гамма, насыщенность и оттенок не меняются; яркость и контраст сбрасываются в 0.
5. Пороги (99 %, уровень 245) вынесены в константы и подбираются на тестовых сканах заказчика.

Если миниатюра недоступна, панель показывает сообщение об ошибке, значения не меняются.

## 8. Совместимость

- Сохранённые в браузере настройки прежнего формата читаются без преобразования: чёрная и белая точки, окраска берут значения по умолчанию, баланс каналов остаётся в прежних единицах.
- Параметр настроек в ссылке содержит одиннадцать чисел в порядке: чёрная точка, белая точка, гамма, яркость, контраст, насыщенность, оттенок, баланс красного, зелёного, синего, окраска (0 вся, 1 гематоксилин, 2 эозин). Ссылки с десятью числами (без окраски) и с восемью (прежний формат: яркость, контраст, гамма, насыщенность, оттенок, баланс красного, зелёного, синего) распознаются по количеству чисел. Профиль сканера в ссылку не входит: у получателя он включён по умолчанию.
- Миниатюра для автокоррекции — та же, что в каталоге (`/api/slides/{id}/thumbnail.jpg`, 320 px).
- Новый маршрут сервера один: `GET /api/slides/{id}/color-lut.png` — таблица цвета 33³ из ICC-профиля файла (PNG 1089 × 33, срезы по синему в ряд), права как у тайлов, кэш на сервере, 404, если профиля нет. Схема базы не меняется. Права на скан проверяются для таблицы так же, как для тайлов и миниатюр: чужой скан отвечает 404.
