### 2.2. Уточнения, внесённые при согласовании

- **Единицы баланса белого.** В дополнении баланс задан коэффициентами 0,5…2, а в коде и ссылках он хранится как −100…+100 (коэффициент `2^(b/100)`). ## 3. Что сделано в коде

### 3.1. Первая редакция панели (коммит `56eece0`)

**Шейдер и расчёты (`adjust.js`).**

- Параметры `black` (0…254) и `white` (1…255); список `PARAMS` в порядке чисел ссылки.
- В шейдер добавлен шаг чёрной и белой точек `(c − black) / (white − black)` между балансом белого и яркостью.
- `applyValues` — та же цепочка на JS для одного цвета (сверка шейдера, расчёты «Авто»).
- `histogramOf`, `percentile`, `sourceHistogram`: гистограмма яркости видимого поля по изображению до коррекций; кадр уменьшается до 256 точек по ширине, чтобы чтение с 2D-canvas не роняло частоту кадров.
- Пресеты по дополнению: «Бледная окраска» (чёрная 20, белая 250, насыщенность +35), «Перекрашенный препарат» (гамма 1,40, белая 245).

**Панель (`adjust-panel.js`, `viewer.html`, `app.css`).**

- Сверху вниз: пресет, гистограмма (корневая ось, затенение за чёрной и белой точками), шкала уровней с тремя маркерами, три числовых поля, кнопки «Авто», пипетка, «До/После», «Сбросить всё», свёрнутый блок «Дополнительно» с ползунками яркости, контраста, насыщенности, оттенка, строкой баланса белого и его сбросом, подписью порядка применения.
- Маркеры: `role="slider"`, перетаскивание с захватом указателя, стрелки ±1 (гамма ±0,05), с Shift в десять раз крупнее, двойной щелчок — значение по умолчанию. Маркер гаммы стоит на логарифмической шкале между чёрной и белой точками, влево — гамма растёт; стрелки идут за маркером.
- Чёрная точка всегда ниже белой: ограничивается тот маркер, который двигался.
- Гистограмма считается только при открытой панели и не чаще 4 раз в секунду (по событию `update-viewport`).
- «Авто» по миниатюре скана; пипетка ставит баланс белого и белую точку по щёлкнутому участку фона.
- Совместимость: сохранённые настройки прежнего формата читаются как есть (недостающие точки — по умолчанию); ссылка несёт десять чисел, прежние с восемью распознаются по количеству.
- Ползунков баланса красного, зелёного, синего больше нет.

**Прочее.** Строки `adjust.*` в `i18n.js`, подсказка кнопки в верхней панели, `toggleAdjust` в `viewer.js` сообщает панели об открытии.

### 3.3. Дополнение по решению заказчика (коммит `be0cd34`)

**«Авто» как в сканере.** `autoValues`: фон — 99-й процентиль каждого канала; баланс белого делает фон нейтральным; белая точка = уровень фона × 255 / 245, не выше 255 — фон ложится на 245, как у сканеров; чёрная точка, гамма, насыщенность и оттенок не меняются; яркость и контраст сбрасываются в 0. Пороги в константе `AUTO`.

**Профиль сканера («Цвет как в сканере»).**

- Сервер: новый модуль `server/color_lut.py` переводит ICC-профиль из файла в таблицу цвета 33³ (littlecms через PIL `ImageCms`, PNG 1089 × 33: срезы по синему в ряд). Маршрут `GET /api/slides/{id}/color-lut.png` с правами как у тайлов, кэш в `data/cache/luts`, отметка `.none` для файлов без профиля (KFB). Настройка `luts_dir` в `config.py`. Схема базы не менялась.
- Клиент: шейдер применяет таблицу первым шагом (трилинейная выборка: по красному и зелёному — текстурой, по синему — вручную); `ImageAdjuster.setLut/setProfile/profileColor`; половина экрана (`slide-view.js`) запрашивает таблицу при открытии, 404 означает отсутствие профиля; отметка «Цвет как в сканере» под пресетом включена по умолчанию, если профиль есть, выключение запоминается в браузере по скану, «Сбросить всё» включает обратно; «Авто» и пипетка считают цвет через ту же таблицу, как его видит шейдер; «До/После» показывает изображение без профиля и без коррекций.
- На рабочем сервере у всех четырёх SVS заказчика есть профиль «ScanScope v1» (сканеры Aperio SS7762 и SS50183), у двух KFB профиля нет. Таблицы построены заранее (0,2–0,4 с каждая); у сканов SS7762 профиль сдвигает цвета в среднем на 42 уровня из 255, у SS50183 — на 13.

**Разделение окрасок.** Параметр «окраска» (вся / только гематоксилин / только эозин): оптические плотности `−ln c`, концентрации через обратную матрицу векторов Ruifrok–Johnston (те же, что «H&E default» в QuPath), обратно оставляется одна окраска. Пресеты «Только ядра (гематоксилин)» и «Только эозин», список «Окраска» в «Дополнительно». Ссылка несёт одиннадцать чисел; ссылки с десятью и восемью читаются как раньше.

**Поиск пресетов патологов.** Опубликованных пресетов уровней и гаммы для трепанобиоптатов не нашлось (статьи, документация ImageScope и QuPath). Из инструментов, разработанных патологами, применимо разделение окрасок — оно и добавлено. Нормализация окраски (Reinhard, Macenko) — отдельная функция, не пресет, не делалась.

### 3.4. Порядок применения коррекций (раздел 7.3 ТЗ)

1. Профиль сканера (таблица цвета).
2. Разделение окрасок.
3. Баланс белого: `c × k`, `k` от 0,5 до 2.
4. Чёрная и белая точки: `(c − black) / (white − black)`.
5. Яркость и контраст: `(c − 0,5) × 3^(контраст/100) + 0,5 + яркость/200`.
6. Гамма: `c^(1/гамма)`.
7. Насыщенность (смешение с яркостью Rec. 709), затем оттенок (поворот вокруг серой оси).

Без профиля, при окраске «вся», чёрной точке 0 и белой 255 изображение совпадает с прежней редакцией при тех же значениях.

## 4. Проверка

**Стенд.** Временная база и три синтетических скана «как костный мозг» 2048 px: 40×, 20× и бледный 20× с тёплым фоном; для профиля на стенд подставлялся настоящий профиль сканера заказчика (профиль устройства, без данных пациента). Проверено в браузере:

- маркеры мышью и стрелками, числовые поля, двойной щелчок, ограничение «чёрная ниже белой», пресеты, «До/После», «Сбросить всё» с гашением индикатора сохранённых настроек, гистограмма после зума;
- «Авто» на бледном скане (фон нейтральный, повторное нажатие даёт тот же результат, чёрная точка не тронута), пипетка по фону (фон стал белым);
- ссылки с восемью, десятью и одиннадцатью числами; настройки из ссылки не записываются в браузер получателя; сохранённые настройки прежнего формата читаются;
- сравнение двух сканов: панель следует за активной половиной, «Применить к обеим» копирует все параметры;
- профиль: отметка включена по умолчанию, выключение прячет слой и запоминается, «Сбросить всё» включает обратно; «Только ядра» и «Только эозин» дают ожидаемые картинки.

**Расчёты.** На Node проверены обратная матрица окрасок (`M·M⁻¹ = I`), сохранение чистого цвета гематоксилина в режиме «только ядра» и его исчезновение в «только эозин», тождественность `applyValues` при значениях по умолчанию, выборка из таблицы цвета.

**Тесты.** Добавлены проверки: таблица цвета чужого скана отвечает 404 (`tests/access_test.py`); у файла без профиля 404 дважды, второй раз по отметке без открытия файла; таблица для профиля sRGB тождественна (`tests/upload_test.py`). Все шесть наборов тестов проходят.

**Не проверено и остаётся за заказчиком.** Частота кадров при движении маркеров настоящей мышью; вид после «Авто» на настоящих сканах на 40×; совпадение изображения при включённом профиле с ImageScope с управлением цветом; значения пресетов и уровень фона 245 — предварительные.
